# Hotel Booking Demand & Cancellation Analytics

This project analyzes hotel booking data to:
- Predict booking cancellations using ML
- Forecast room-wise demand
- Perform month-wise forecasting using ARIMA
- Provide an interactive Streamlit dashboard

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- SQLite
- Statsmodels

## How to Run
```bash
pip install -r requirements.txt
streamlit run app/app.py
